# Experiment 2 - Living Impressions
Probably my favorite experiment, assignment 2 had us generate a living impression of an image. Seen [here](https://studentalleg.github.io/cmpm147/experiment2/index.html), the generator I created generates an overhead view as if the camera is traversing upwards, [like some of those stock waiting images](https://mixkit.co/free-stock-video/aerial-overhead-shot-of-a-highway-in-a-city-49830/). The effect turned out well and there are interesting techniques used to generate this image.
